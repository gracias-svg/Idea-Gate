# Purpose

Information hierarchy determines what users notice first.

Users should never have to search for the most important information.

The interface should naturally guide attention through structure rather than visual noise.

Every screen should answer, in order:

1. Where am I?
2. What is happening?
3. What should I do next?
4. Why does it matter?
5. What additional context is available?

---

# Design Philosophy

Information should feel curated.

Not dumped.

Not hidden.

Not overwhelming.

The product should feel like an experienced Product Manager preparing information for another experienced Product Manager.

---

# Core Principles

## Principle 1

One Primary Message

Every screen should have exactly one dominant purpose.

Users should understand the purpose within two seconds.

Examples

Desk

Reading

Studio

Improving

Office

Observing

Blueprint

Understanding

Mission Control

Monitoring

Never mix multiple primary purposes.

---

## Principle 2

Progressive Disclosure

Reveal information in layers.

Layer 1

Essential

Layer 2

Supporting

Layer 3

Advanced

Layer 4

Developer

Most users should never need Layer 4.

---

## Principle 3

Context Before Detail

Always provide context before presenting details.

Good

Stage 6

↓

Research Complete

↓

Generated by Research Agent

↓

Last Updated

↓

View Details

Bad

Large metadata table with no explanation.

---

## Principle 4

Decision Before Data

Show decisions before evidence.

Example

Approved

↓

Why

↓

Supporting Analysis

↓

Raw Logs

Never reverse this order.

## Level 2

## Level 3

## Level 4

↓

# Metadata Strategy

Metadata should support content.

Never dominate it.

Show only metadata users can act upon.

Hide passive information until requested.

---

# Context Panels

Context panels should answer

Why?

Who?

When?

Dependencies?

Related artifacts?

Avoid duplicating the primary workspace.

---

# Status Indicators

Status should communicate meaning instantly.

Preferred states

Draft

In Review

Approved

Blocked

Generating

Completed

Archived

Avoid ambiguous labels.

---

# Confidence Display

Confidence should always include context.

Good

92%

Based on 12 sources

Bad

92%

No explanation.

---

# AI Reasoning

Reasoning should be collapsible.

Default view

Summary

Expanded view

Reasoning

Evidence

Confidence

References

Raw generation

Users should not be forced to read reasoning.

---

# Agent Activity

Office should emphasize

Current work

Progress

Coordination

Dependencies

Completed work

Avoid showing every internal event.

Filter noise automatically.

---

# Blueprint

Blueprint should prioritize

Lifecycle

Dependencies

Relationships

Critical paths

Health

Advanced graph diagnostics remain secondary.

---

# Mission Control

Mission Control should answer

What needs attention?

before

What happened?

Exceptions should always outrank historical metrics.

---

# Empty States

Empty states should educate.

Every empty state should answer

Why is this empty?

What should happen next?

How do I begin?

---

Current project

Current artifact

↓

Related artifacts

↓

Commands

↓

History

↓

# Error Information

Errors should be layered.

Summary

↓

Explanation

↓

Suggested Fix

↓

Technical Details

---

# AI Suggestions

Recommendation

↓

Reason

↓

Impact

↓

Confidence

↓

Accept

↓

Reject

↓

---

# Visual Noise Reduction

Avoid displaying

Every timestamp

Every ID

Every system field

Every intermediate state

Every debug event

Show information that influences decisions.

Everything else belongs behind progressive disclosure.

---

# Dashboard Philosophy

Dashboards summarize.

They do not replace detailed workspaces.

Users should drill into work rather than perform work inside dashboards.

---

# Quality Checklist

Before approving any screen ask

[ ] Can users identify the primary message within two seconds?

[ ] Is critical information always visible?

[ ] Are advanced details progressively disclosed?

[ ] Does metadata support rather than dominate?

[ ] Are AI explanations optional but accessible?

[ ] Does the screen feel calm?

[ ] Would removing information improve clarity?

If yes, remove it.

---

# Non-Negotiables

Never display technical information before user information.

Never overload users with metadata.

Never expose every AI event.

Never prioritize completeness over comprehension.

Information hierarchy exists to reduce cognitive effort.
