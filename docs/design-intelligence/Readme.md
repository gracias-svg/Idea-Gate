# Design Intelligence Library

## Purpose

This folder contains the visual research that guides the evolution of IdeaGate's design system.

It is the primary research source for premium SaaS UI/UX decisions.

---

## Contents

### Design Intelligence Library.pdf

Curated design knowledge.

Each reference contains:

- Screenshot
- DIL ID
- Source
- Why Saved
- Design Problem Solved
- IdeaGate Mapping
- What to Copy
- What to Avoid
- Innovation Opportunity

This is the primary reference document.

---

### DIL - RAW.pdf

Raw extraction of all collected references.

Contains additional observations, screenshots, notes, translations and exploratory thinking before curation.

This document is for research only.
