# Purpose

This document defines every major IdeaGate workspace.

Every workspace has

- One responsibility
- One mental model
- One primary objective

No screen should duplicate another.

Together they form one Product Operating System.

---

# Screen Quality Checklist

Before approving any screen ask

[ ] Does the screen have one clear responsibility?

[ ] Can users understand its purpose within five seconds?

[ ] Does AI support rather than dominate?

[ ] Does it integrate naturally with every other workspace?

[ ] Can future capabilities be added without redesign?

[ ] Does it feel like part of one operating system?

---

# Non-Negotiables

Never duplicate responsibilities across screens.

Never build isolated experiences.

Never prioritize visual novelty over operational clarity.

Every screen exists to support one stage of product thinking.
